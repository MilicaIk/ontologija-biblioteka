ПРОВЕРА СЛИКЕ 2 НА ВИКИПОДАЦИМА
Оба упита се налепе на https://query.wikidata.org и покрену (дугме ▷).

────────────────────────────────────────────────────────────────────────
УПИТ 1 — називи и описи свих класа са слике
Проверава да ли сваки QID заиста означава класу под тим називом.
────────────────────────────────────────────────────────────────────────

SELECT ?klasa ?naziv_sr ?naziv_en ?opis_en WHERE {
  VALUES ?klasa {
    wd:Q178706 wd:Q141507421 wd:Q58326331 wd:Q3152824 wd:Q7075
    wd:Q28564 wd:Q2326815 wd:Q114617264 wd:Q1438040 wd:Q856234
    wd:Q1622062 wd:Q2586205 wd:Q121306790 wd:Q65768782 wd:Q22806
    wd:Q327333 wd:Q6256 wd:Q56061 wd:Q43229 wd:Q5 wd:Q210272
  }
  OPTIONAL { ?klasa rdfs:label ?naziv_sr
             FILTER(LANG(?naziv_sr) IN ("sr", "sr-ec", "sr-el")) }
  OPTIONAL { ?klasa rdfs:label ?naziv_en FILTER(LANG(?naziv_en) = "en") }
  OPTIONAL { ?klasa schema:description ?opis_en FILTER(LANG(?opis_en) = "en") }
}
ORDER BY ?klasa

────────────────────────────────────────────────────────────────────────
УПИТ 2 — провера сваке везе P279 нацртане на слици
Колона "neposredno" мора бити true тамо где је на слици пуна линија,
а "posredno" true тамо где је испрекидана (P279*). Ако је обоје false,
веза на слици не постоји на Википодацима.
────────────────────────────────────────────────────────────────────────

SELECT ?dete ?deteLabel ?roditelj ?roditeljLabel ?neposredno ?posredno WHERE {
  VALUES (?dete ?roditelj) {
    (wd:Q3152824   wd:Q178706)      # установа културе → установа
    (wd:Q3152824   wd:Q141507421)   # установа културе → културна организација
    (wd:Q7075      wd:Q3152824)     # библиотека → установа културе
    (wd:Q7075      wd:Q58326331)    # библиотека → пружалац информационих услуга
    (wd:Q28564     wd:Q7075)        # јавна библиотека → библиотека  (пуна)
    (wd:Q1438040   wd:Q7075)        # истраживачка библиотека → библиотека  (испрекидана)
    (wd:Q2586205   wd:Q7075)        # научна библиотека → библиотека  (испрекидана)
    (wd:Q65768782  wd:Q7075)        # библиотека државног органа → библиотека  (испрекидана)
    (wd:Q2326815   wd:Q28564)       # општинска → јавна
    (wd:Q114617264 wd:Q2326815)     # градска → општинска
    (wd:Q856234    wd:Q1438040)     # академска → истраживачка
    (wd:Q1622062   wd:Q856234)      # универзитетска → академска
    (wd:Q121306790 wd:Q2586205)     # математичка → научна
    (wd:Q22806     wd:Q65768782)    # национална → библиотека државног органа
    (wd:Q22806     wd:Q327333)      # национална → јавна агенција
  }
  BIND(EXISTS { ?dete wdt:P279 ?roditelj }  AS ?neposredno)
  BIND(EXISTS { ?dete wdt:P279+ ?roditelj } AS ?posredno)
  SERVICE wikibase:label { bd:serviceParam wikibase:language "sr,en". }
}

НАПОМЕНА О НАЗИВИМА
Ове класе немају српску ознаку на Википодацима, па су називи на слици
преводи енглеских ознака:
  Q141507421  cultural organization        → културна организација
  Q58326331   information service provider → пружалац информационих услуга
  Q114617264  city library                 → градска библиотека
  Q121306790  mathematics library          → математичка библиотека
  Q65768782   government library           → библиотека државног органа
Ако упит 1 покаже да је српска ознака у међувремену додата, најбоље је
употребити њу.
